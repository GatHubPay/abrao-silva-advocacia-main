## Como Personalizar

### Adicionar Imagem dr.png
1. Adicione a imagem `dr.png` na pasta `/public/`
2. Dimensões recomendadas: 400x500px
3. Formato PNG com fundo transparente ou branco

### Adicionar Vídeo
1. **YouTube**: Descomente `videoId` e adicione o ID do vídeo
2. **Local**: Adicione o vídeo em `/public/videos/` e use `videoUrl`

### Personalizar Informações
- Edite as props do `HeroSection` para alterar textos e informações
- Modifique os dados de contato na seção correspondente
- Ajuste cores no arquivo de estilos se necessário
